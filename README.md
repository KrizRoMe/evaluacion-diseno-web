## 📚 Conceptos que puedes aplicar

- WCAG / POUR (Perceptible · Operable · Comprensible · Robusto).
- 10 heurísticas de Nielsen.
- ISO 9241-11 (efectividad · eficiencia · satisfacción).
- Ley de Hick (más opciones = más tiempo para decidir).
- Ley de Miller (7±2) y chunking.
- Ley de Fitts (targets pequeños cuestan más).
- Principios Gestalt (proximidad · similitud · cierre).
- Carga cognitiva.
- Dark patterns (preselección · costos ocultos · cancelación difícil · botones engañosos · alternativas escondidas).
- Ética digital.

## 📊 Cómo se califica

Cada Issue vale **6 puntos**:

| Criterio | Puntos |
|---|---|
| A. Identificación del problema | 1.0 |
| B. Reproducción / evidencia | 1.0 |
| C. Relación con principios/conceptos | 1.5 |
| D. Impacto | 1.0 |
| E. Severidad justificada | 0.5 |
| F. Solución | 1.0 |
| **Subtotal por Issue** | **6.0** |

Calidad global (2 puntos):

| Criterio | Puntos |
|---|---|
| Aplicación de contenidos (variedad) | 1.0 |
| Calidad global del análisis | 1.0 |
