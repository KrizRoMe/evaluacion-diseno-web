## 📝 Rúbrica por Issue (6 puntos)

### A. Identificación del problema — 1 punto

| Puntaje | Criterio |
|---|---|
| **1.0** | El problema existe y está claramente identificado. |
| **0.5** | Existe pero está descrito de manera poco precisa. |
| **0** | No existe o no se entiende. |

### B. Reproducción / evidencia — 1 punto

| Puntaje | Criterio |
|---|---|
| **1.0** | Indica claramente dónde ocurre y cómo comprobarlo. |
| **0.5** | La ubicación es parcialmente clara. |
| **0** | No permite comprobarlo. |

### C. Relación con principios/conceptos — 1.5 puntos

| Puntaje | Criterio |
|---|---|
| **1.5** | Relaciona correctamente el problema con un concepto visto y explica la relación. |
| **1.0** | El concepto es correcto pero la explicación es superficial. |
| **0.5** | La relación es parcialmente correcta. |
| **0** | No existe relación válida. |

**Conceptos válidos (no exhaustivo):** WCAG · POUR · Nielsen · ISO 9241 · Hick · Miller · Fitts · Gestalt · carga cognitiva · dark pattern · accesibilidad · usabilidad.

### D. Impacto — 1 punto

| Puntaje | Criterio |
|---|---|
| **1.0** | Explica claramente cómo afecta al usuario. |
| **0.5** | Menciona un impacto razonable pero superficial. |
| **0** | No explica el impacto. |

### E. Severidad — 0.5 puntos

| Puntaje | Criterio |
|---|---|
| **0.5** | Severidad razonable y justificada. |
| **0.25** | Razonable pero débilmente justificada. |
| **0** | Incoherente. |

### F. Solución — 1 punto

| Puntaje | Criterio |
|---|---|
| **1.0** | Solución concreta y razonable. |
| **0.5** | Solución general pero razonable. |
| **0** | No propone solución o es incorrecta. |

## 🚫 Lo que NO se evalúa (requisitos de entrega, no de contenido)

- Que haya creado la Issue.
- Que haya hecho commit o push.
- Formato del título.
- Que haya usado GitHub correctamente.
- Que haya adjuntado capturas (opcional).
- Gramática perfecta.

---

## ⚖️ Política sobre problemas no verificables

| Situación | Acción |
|---|---|
| Hallazgo existe en CanchaYa | Evaluar normalmente. |
| Hallazgo no aparece literal pero es consecuencia de uno real | Aceptar si hay evidencia. |
| Hallazgo genérico ("la página es fea") | A: 0.5 · resto: según coherencia. |
| Hallazgo inventado | A: 0 · resto: 0. |
| Hallazgo correcto pero principio equivocado | A: 1.0 · C: 0. |
