## 🧮 Cálculo final

```
Suma = Issue 1 + Issue 2 + Issue 3 + Globales
Redondeo = round(Suma × 2) / 2     # al medio punto más cercano
Resultado = "APROBADO" si Redondeo >= 14 sino "DESAPROBADO"
```

## ⚠️ Casos especiales

- [ ] Hallazgo inventado o no verificable → marcar y revisar en CanchaYa.
- [ ] Issue sin plantilla → revisar si tiene las 8 secciones.
- [ ] Dos Issues casi idénticas → reportar (posible copia).
- [ ] Issue con lenguaje inapropiado → 0 en contenido.
- [ ] README ausente → no restar puntos (opcional).
- [ ] Entrega fuera de plazo → avisar al docente.
