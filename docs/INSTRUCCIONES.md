# Instrucciones — Evaluación Práctica Diseño y Desarrollo Web

**Duración:** 90 minutos · **Modalidad:** Individual

---

## ⏱️ Antes de empezar (5 min)

1. Abre **CanchaYa** en una pestaña: <https://krizrome.github.io/evaluacion-diseno-web/>
2. Abre una **segunda pestaña** con el repositorio para crear Issues: <https://github.com/KrizRoMe/evaluacion-diseno-web/issues/new/choose>
3. Abre una **tercera pestaña** (o un editor) para tomar notas rápidas.
4. Verifica que tienes la extensión **axe DevTools** instalada en Chrome.

---

## 🔍 Fase 1 — Exploración (10–15 min)

Recorre CanchaYa siguiendo estos pasos. **No anotes nada todavía**, solo observa:

- 🏠 **Home:** mira cuántos deportes aparecen y cómo están organizados.
- 📋 **Listado de canchas:** usa los filtros de la barra lateral.
- 🎯 **Detalle de una cancha:** revisa la imagen, los horarios y el formulario.
- 📝 **Llena el formulario** con datos incorrectos a propósito para ver qué pasa.
- ✅ **Confirma una reserva** y observa la pantalla de éxito.
- 👤 **Ve a Mi cuenta** y fíjate qué botones hay.

---

## ✏️ Fase 2 — Selección y análisis (20 min)

De todo lo que viste, elige **3 problemas** que te parezcan importantes. Recomendación:

- 🧩 **Problema 1** → accesibilidad (WCAG / POUR).
- 🎯 **Problema 2** → usabilidad (Nielsen · ISO · Gestalt).
- 🧠 **Problema 3** → psicología cognitiva (Hick · Miller · Fitts) **o** dark pattern.

> 💡 Tres problemas válidos de la misma categoría también puntúan.

Para cada problema redacta tu hallazgo respondiendo las **secciones obligatorias**:

1. **Problema** — qué pasa.
2. **Ubicación / reproducción** — pasos concretos.
3. **Principio relacionado** — concepto visto en clase y por qué aplica.
4. **Justificación** — por qué afecta la experiencia.
5. **Impacto** — a quién afecta, qué dificultad genera.
6. **Severidad** — baja / media / alta + justificación.
7. **Evidencia** — captura o descripción.
8. **Solución propuesta** — concreta y verificable.

---

## 📤 Fase 3 — Crear las GitHub Issues (35 min)

Para cada uno de tus 3 hallazgos:

1. Ve a <https://github.com/KrizRoMe/evaluacion-diseno-web/issues/new/choose>
2. Selecciona la plantilla **"Reporte de Hallazgo"**.
3. Llena **todos los campos interactivos** (selects, checkboxes, áreas de texto).
4. Verifica que la etiqueta `hallazgo-usabilidad` quede aplicada.
5. Envía.

Repite **3 veces — exactamente 3 Issues**.

---

## 📝 Fase 4 — README del estudiante (5 min)

En el repositorio, haz clic en **Add file → Create new file** y nómbralo `README.md` (en la raíz, no en `docs/`).
Copia y pega:

```markdown
# Evaluación Práctica — Diseño y Desarrollo Web

## Datos

**Nombre:** [Tu nombre completo]

## Objetivo

Auditar la interfaz de CanchaYa y documentar tres hallazgos.

## Issues

- **Issue 1:** [URL]
- **Issue 2:** [URL]
- **Issue 3:** [URL]

## Reflexión final

¿Cuál de tus tres hallazgos consideras más importante? ¿Por qué?
```

---

## ✅ Fase 5 — Revisión final (5 min)

Antes de entregar verifica:

- [ ] Tengo **exactamente 3 Issues** abiertos.
- [ ] Cada Issue usa la plantilla.
- [ ] Cada Issue tiene las 8 secciones completas.
- [ ] Cada Issue tiene la etiqueta `hallazgo-usabilidad`.
- [ ] Tengo el README en la raíz con mis datos + URLs.
